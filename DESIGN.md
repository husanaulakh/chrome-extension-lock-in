# Design

Use a quiet white surface, a light grey background, dark system typography and restrained blue actions. Rounded cards group decisions; spacing gives the task and timer priority. No remote fonts or decorative illustrations are needed.

Setup begins with task, destination, duration and commitment. Additional resources and custom rules open on request. Dashboard is a separate view; it never competes with the active session. Figures come from actual records, with explicit empty states.

The interface does not advertise pricing or storage architecture. Those details belong in documentation and privacy information. Copy states an action or consequence without motivational slogans, guilt, or inflated claims. Controls have visible focus states and labels; layouts adapt to narrow screens.

The visual direction uses the restraint of familiar native settings interfaces without copying Apple assets. The implementation follows the user's [OpenDesign reference](https://github.com/nexu-io/open-design) by keeping design decisions in a reviewable file, and their [writing reference](https://en.wikipedia.org/wiki/Wikipedia:Signs_of_AI_writing) by keeping claims specific.

## Combined direction

The current revision restores the original “One thing. For a little while.” heading, Georgia italic emphasis, cobalt blue (#2851df) and darker slate text (#23344a). It retains rounded controls, expandable resources and custom settings, and a separate dashboard. Secondary text has stronger contrast and no text is smaller than 12px in the preview.

Use last setup appears only after a recorded session. It fills the form for review and resets all session activity. It is hidden in private extension windows. The active timer includes the finish time so users can judge whether an extension fits the rest of their day.
