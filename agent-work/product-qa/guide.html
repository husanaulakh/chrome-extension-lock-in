Your focus, your boundaries.

Name your task, choose its website, set a duration, and start. Save open work first: disallowed pages redirect.

Website or exact URL?

Entire website allows every page on the specified hostname. It does not automatically allow subdomains. Only this exact URL also checks the path, query, and # route. For a single exam page, paste the complete address, choose exact URL, keep “Only allowed resources,” and leave additional resources empty.

Network rules permit the underlying document. Full # fragments and single-page-app route changes are checked when the browser reports navigation, so a disallowed route can appear briefly before redirecting. The extension does not verify exam software or protect exam integrity.

More resources

Use “More resources & blocking rules” to reveal additional permissions. Enter one resource per line. A hostname permits its pages; a full path permits that exact URL. An additional hostname can intentionally widen an exact-page session.

“Block selected domains” keeps other sites available. Domain blocks include subdomains and override allowed resources and access grants. A blocked focus website is rejected at setup.

Time and commitment

Start with 1–480 minutes. Add 1–480 minutes during an active session, up to a total of 24 hours. Adding time cannot change rules or reset an exit wait. Existing access grants retain their original expiry.

Light permits an immediate exit. Committed requires at least 60 seconds; Locked requires at least 15 minutes and disables temporary access. Customization can increase the exit wait to 30 minutes and configure 0–10 access requests of 1–30 minutes each. Settings are fixed when the session starts. Recovery always remains available.

Private windows

Enable “Allow in Incognito” in Chrome/Edge extension settings or “Run in Private Windows: Allow” in Firefox’s add-on settings. The popup shows whether access is enabled. The extension cannot turn this setting on itself.

When enabled, session rules cover private windows in this profile. Private browsing attempts are not recorded. A session started in a private window uses memory-only storage and rules, creates no saved history, and ends when the browser closes. A regular session’s title and deliberate resource grants remain in its normal saved state, even when changed from a private window.

Dashboard

Open Dashboard from the popup or the browser’s extension options. It is included in the extension and works without a server. Review session time, completed sessions, recorded distractions, daily activity, and recent outcomes. Use Export for a JSON backup. History deletion requires confirmation and is unavailable during an active session.

Recovery and limits

Use “Need to leave? → Technical recovery” to end immediately. If the extension itself fails, disable it in browser settings. Other browsers, profiles, browser settings, embedded content, and desktop applications remain outside its control. Users can disable the extension or change the clock. It is a voluntary focus aid, not tamper-proof control.

Browser alarms may be delayed during sleep or heavy load. Redirecting an existing document can lose unsaved work. The extension does not close windows, restore discarded form state, or block downloads. Exact login redirects must be added explicitly.
